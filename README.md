## Описание

Задача основана на нашумевшем исследовании «BFId: Identity Inference Attacks Utilizing Beamforming Feedback Information» (ACM CCS 2025, DOI: 10.1145/3719027.3765062). Его авторы показали, что по Beamforming Feedback Information (BFI) — служебной информации, которую Wi-Fi-устройства передают в открытом виде, — можно определять личность человека, находящегося в зоне действия сети. Все данные задачи взяты из этого исследования: записи — это многоканальные BFI-сэмплы, а identity — идентификаторы участников эксперимента.

Участникам выдаётся размеченный обучающий набор многоканальных записей, неразмеченный тестовый набор и таблица соответствия identity → символ. Каждый класс (identity) задаётся парой признаков: несущей частотой и межканальным фазовым шаблоном — набором относительных сдвигов фаз между каналами. Абсолютная начальная фаза каждой записи случайна и неизвестна.

Обучающий набор отравлен двумя способами. Во-первых, в часть сэмплов вшит бэкдор: в начале записи стоит OOD-триггер, не похожий на остальной сигнал. Во-вторых, метки загрязнены так, что для части классов сэмплы с чужой частотой составляют большинство, поэтому выбор «самого крупного кластера внутри метки» даёт неверный эталон класса. В тестовые записи добавлена помеха с плоской (одинаковой по каналам) фазой, которая ломает классификацию по энергии и по частоте. Модель, обученная на данных как есть, выдаёт правдоподобный, но неверный флаг.

## Решение

Отбросить сэмплы с OOD-триггером в начале записи (бэкдор)
Кластеризовать все сэмплы глобально по частоте (по разрывам), для каждой метки выбрать "домашний" кластер по чистоте (purity), а не по размеру — это ключевой трюк против contamination-majority
По очищенным данным оценить частоту + межканальный фазовый шаблон (относительный, без привязки к неизвестной фазе записи)
Классифицировать тест через фазовый matched filter (когерентное суммирование по каналам с поворотом на -Δφ) — устойчиво к помехе с плоской фазой
Декодировать identity → char → собрать флаг
